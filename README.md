# 📋 USDT/TWD 刷發票秘書

MAX 交易所的自動小幫手：把帳上的 **USDT（數位美元）和台幣維持各一半**，每天自動成交一筆小單，讓 MAX **每天開一張電子發票**給你拿去對獎。

> 目的是每天一張發票，不是賺價差。

## 💰 成本與期望值

| 項目 | 金額 |
|---|---|
| 策略成本 | 每年約 **365 元**（保守估計；回測實際約 200~250 元） |
| 發票 | 每天 1 張，一年 **365 張** |
| 發票期望值 | 目前約 2 元／張 → 一年約 **730 元** |
| **策略成本 APR** | **≈ 100%** = (730 − 365) ÷ 365 |

- 分母是**每年花掉的成本**，不是本金。
- ⚠️ 這是**對獎的期望值，不是保證報酬**。期望值大多來自很少出現的大獎，多數人實際拿到的會比 730 元少，少數人會多很多，取決於自身運氣。
- 一半資金是 USDT，會跟著美金匯率漲跌（近一年最大回撤約 1.5%）。

## 🚀 怎麼用

1. 下載 `usdttwd_secretary.py`。
2. 用記事本打開，把最上面兩行換成你的金鑰：
   ```python
   API_KEY = "貼上你的 API KEY"
   API_SECRET = "貼上你的 API SECRET"
   ```
3. 執行：
   ```
   python3 usdttwd_secretary.py        # Windows 打：python usdttwd_secretary.py
   ```
4. **視窗不要關。** 程式會自己做這些事，關掉的那天就沒有發票：
   - 08:01 掛單
   - 每 10 分鐘檢查一次
   - 23:55 補單

其他指令：

```
python3 usdttwd_secretary.py status        # 看餘額和今天的手續費
python3 usdttwd_secretary.py open --dry    # 試算今天會怎麼掛單，不會真的下單
```

## ⚙️ 運作原理

| 時間 | 做什麼 |
|---|---|
| 08:01 | 看半夜 00:00–08:00 的最高價和最低價，在現價下方掛買、上方掛賣，數量是成交後剛好回到 1:1 |
| 每 10 分鐘 | 一邊成交了，就撤掉另一邊，依新的持倉重新算量再掛 |
| 23:55 | 今天手續費合計還不到 0.5 元，就直接吃單補一筆（方向朝 1:1），23:58 再檢查一次 |

- 發票規則：**當天手續費合計四捨五入 ≥ 1 元**才會開，隔天開立。這是實測反推出來的，網路上「最低 1 元」的說法不正確。
- 手續費率會自動偵測你的 VIP 等級，以及有沒有用 MAX 幣折抵。

## ⚠️ 注意

- 帳上**所有**的 USDT 和台幣都會被拿來做 1:1。如果你平常在同一個帳戶放大筆台幣或 USDT，最好開子帳戶，或只放刷發票用的錢。其他幣（BTC、ETH……）不會動。
- 每天 08:01 會撤掉 USDT/TWD 市場上的所有掛單，包括你自己手動掛的。
- 本程式不是投資建議。
